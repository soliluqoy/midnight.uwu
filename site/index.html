A connection, by choice

Find each other.
Then make it direct.

Keep both apps running throughout setup. There’s no central account directory and no mailbox waiting for an offline friend.

  1. 01

    Pair with your person

    In Chats, choose Pair a phone on Windows or Show pairing code on Android. On the other device, scan the code on Android or enter the copied code text on Windows. Confirm the complete fingerprints with each other.

  2. 02

    Choose your connection setup

    Manual signaling is the default: exchange every queued frame and its replies within the retry deadlines. The optional internet preset uses a third-party public broker after your confirmation to exchange connection signaling—not your messages.

  3. 03

    Connect, then say hello

    Open the contact and choose Connect. Send once the session is authenticated. Both devices must stay awake and directly reachable; some network pairs won’t connect. There is no relay fallback.

Clear boundaries. No fine print.

Personal doesn’t mean
without limits.

Midnight makes deliberate trade-offs. Please understand them before trusting it with a conversation, a library, or an identity you want to keep.

01 / Availability

No mailbox. No relay.

No TURN, push wakeup, cloud sync or automatic offline resend. Both peers must be awake, running and directly reachable. Firewalls, NAT and mobile background limits can prevent delivery. A foreground service is not a guarantee of availability.

02 / Local storage

Your device is a boundary.

Identity keys use OS-protected storage, but local conversation history is not encrypted at rest. There is no automatic identity recovery. Uninstalling, clearing data or losing identity storage can mean losing that identity permanently.

03 / Third-party services

No backend operated by us.

No accounts, telemetry or crash reporting. The optional internet preset uses broker.emqx.io:8883 for encrypted signaling. The broker sees connection metadata and has no availability guarantee. Public listings are a separate opt-in; chat text and media do not go through MQTT.

04 / Sharing

Permission isn’t a time machine.

Library approval includes browsing, playing and downloading the selected library, including future imports and refreshes during the grant. Revoking access stops future delivery; it cannot recall copies already received or exported.

✳

A preview, with open questions.

This software has not undergone an independent cryptographic review. Broader physical-device, network, lifecycle, security and performance gates remain open. A successful build or a single connection does not establish release readiness. Don’t rely on this preview for critical communication.
